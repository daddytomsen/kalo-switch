# kalo’switch

Rechnet Lebensmittel über gleiche Kilokalorien ineinander um – z. B. **1 Riegel Duplo ≈ 1 Handvoll Salzbrezeln**.
Läuft als Web-App in Safari auf dem iPhone (Teilen → „Zum Home-Bildschirm“).

- 137 recherchierte und gegengeprüfte Lebensmittel (kcal, typische Portionen, Handvoll)
- „Handvoll“ = leicht gewölbte, locker gefüllte Hand eines durchschnittlichen Erwachsenen (≈ 70 ml); Werte streuen um etwa ±30 %
- Foto mit Barcode → Nährwerte von [Open Food Facts](https://world.openfoodfacts.org) (ODbL)
- optional: Produkterkennung per Foto mit eigenem Claude-API-Schlüssel (bleibt nur auf dem Gerät)

Alle Werte sind Richtwerte.
